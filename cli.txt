# ==============================================================================
# HƯỚNG DẪN KHỞI CHẠY VPS-INFRA VỚI CLOUDFLARE TUNNEL (FILE CONFIG.YML)
# ==============================================================================

# 1. Cài đặt cloudflared CLI (nếu chưa có) và đăng nhập tài khoản Cloudflare:
#    cloudflared tunnel login
#    (Lệnh này sẽ mở trình duyệt để bạn chọn domain phungvip.io.vn)

# 2. Tạo Tunnel mới (đặt tên ví dụ: ridehub-tunnel):
#    cloudflared tunnel create ridehub-tunnel
#    -> Lệnh này sẽ hiển thị Tunnel ID (UUID) và sinh file ~/.cloudflared/<TUNNEL_ID>.json

# 3. Copy file credentials vào thư mục central-server-config:
#    cp ~/.cloudflared/<TUNNEL_ID>.json ./central-server-config/cloudflared/credentials.json
#    -> Mở file ./central-server-config/cloudflared/config.yml và điền TUNNEL_ID của bạn vào dòng "tunnel: YOUR_TUNNEL_ID"

# 4. Định tuyến DNS Wildcard trên Cloudflare trỏ về Tunnel (chạy 1 lần):
#    cloudflared tunnel route dns ridehub-tunnel "*.phungvip.io.vn"
#    cloudflared tunnel route dns ridehub-tunnel "phungvip.io.vn"

# 5. Chuẩn bị file môi trường & sinh SSL cho Kafka nội bộ:
#    cp .env.example .env
#    set -a && source .env && set +a
#    bash central-server-config/kafka/generate-kafka-ssl.sh

# 6. Khởi chạy toàn bộ hạ tầng (dùng image chính thức, không cần compile/build):
#    docker compose up -d

# 7. Kiểm tra trạng thái:
#    docker compose ps
#    docker compose logs -f cloudflared
#    docker compose logs -f nginx
#    docker compose logs -f keycloak

# ==============================================================================
# BẢO VỆ CÁC TRANG QUẢN TRỊ BẰNG CLOUDFLARE ZERO TRUST (ACCESS):
# 1. Truy cập https://one.dash.cloudflare.com/ (Zero Trust Dashboard)
# 2. Vào Settings -> Authentication -> Add New (chọn One-time PIN qua Email hoặc OpenID Connect trỏ về Keycloak)
# 3. Vào Access -> Applications -> Add an application:
#    - Tên ứng dụng: Kafka UI, Domain: kafdrop.phungvip.io.vn
#    - Tên ứng dụng: Consul UI, Domain: consul.phungvip.io.vn
#    - Tên ứng dụng: RedisInsight, Domain: redisinsight.phungvip.io.vn
# 4. Khi truy cập, Cloudflare sẽ tự động chặn và yêu cầu xác thực trước khi cho vào VPS!
# ==============================================================================
